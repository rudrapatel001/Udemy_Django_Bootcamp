# 🧠 Taskly - Django REST API Project

Welcome to **Taskly**, a fully functional and production-ready RESTful API built using **Django** and the **Django REST Framework (DRF)**. This project was developed while following the **"Django REST API Bootcamp"** course on Udemy.

Taskly demonstrates how to build robust, scalable, and secure backend APIs using modern best practices. From JWT authentication to deployment on Heroku and integration with Google Cloud for media storage—this is a full-stack-ready API backend!

---

## 📚 What I Learned

- Build RESTful APIs using Python and Django REST Framework
- JWT and OAuth2 based authentication
- CRUD functionality with Django ORM
- Media file upload and sharing
- Permissions & custom access control
- Filtering, searching, pagination & throttling
- Background jobs using signals or Celery
- PostgreSQL and SQLite database integration
- Deploy to Heroku with production settings
- Use Google Cloud Storage for media (CDN)
- Use Postman to test your API
- And much more...

---
